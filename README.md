# video-flow-skills

AI 短片／繪本動畫出片流程 skill（Eian 流程・Wong 版）。

核心原則：**錯喺平嗰關捉，唔留到貴嗰關** — 文字 → 圖 → 片，逐關審核過先准入下一關；生片使真錢之前，必先過獨立審核＋報價批准。

- `SKILL.md` — 完整 9 關 checklist：規格 → 故事 → 分鏡 → 畫風／設定圖 → 首尾幀 → 七段式提示詞＋提交前審核 → 生片 → code 後期 → 全片覆核 → 出街檢查，附 Seedance 型號／尾幀能力核實、實測價錢、出事修正次序、同一個已驗證實例（2026-11-06 賣火柴主鏡試片，評分 6／6）。

來源：改編自 Eian @EianLu 嘅 X 長文《Claude Code / Codex + Seedance AI 視頻：從一個想法到成片的全流程》（2026-11-05），再按實測經驗修訂。
